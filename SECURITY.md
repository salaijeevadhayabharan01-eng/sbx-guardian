# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SBX Guardian, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Email: admin@sbxguardian.com

We will respond within 48 hours and work with you to resolve the issue.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | ✅ Yes    |
| 1.x     | ❌ No     |
